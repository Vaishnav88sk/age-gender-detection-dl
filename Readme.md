# 👤 Age & Gender Detection (Deep Learning)

## 📌 Overview
This project detects **age and gender** from images using a custom deep learning model trained on the UTKFace dataset.

## 🚀 Features
- 📸 Image Upload
- 🧠 Deep Learning (CNN)
- 🎯 Real-time prediction
- 🎨 Clean UI with Streamlit

## 🧠 Model
- Custom CNN model
- Trained on UTKFace dataset
- Gender accuracy ~90%
- Age MAE ~7 years

## 🛠️ Tech Stack
- Python
- TensorFlow / Keras
- OpenCV
- Streamlit

## ▶️ Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
